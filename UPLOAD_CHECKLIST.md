# Upload Checklist

1. Create public GitHub repo: `axezent-ai-prk-fuzzer`
2. Do not add GitHub README/license/gitignore.
3. Extract the ZIP.
4. Upload all files inside the extracted folder.
5. If `.github` does not upload, create `.github/workflows/main.yml` manually.
6. Paste `GITHUB_WORKFLOW_MAIN.yml` into that workflow file.
7. Commit.
8. Confirm GitHub Actions is green.
9. Create release `v1.0.0`.
