# Contributing

Thanks for helping improve Axezent AI PRK-Fuzzer.

Good contributions include:

- clearer receipt schemas
- new controlled mutation types
- stronger benchmark reports
- additional reduction generators
- documentation updates
- Python/Rust runtime improvements
- source-audit improvements

Please keep all claims truth-safe. Do not describe this project as resolving P vs NP, proving global solver correctness, or automating all of complexity theory.
