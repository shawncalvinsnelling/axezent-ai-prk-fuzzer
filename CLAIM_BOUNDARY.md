# Claim Boundary

Axezent AI PRK-Fuzzer is a deterministic finite receipt generator and stress-test tool.

Accepted public claim:

> Given a seed and configuration, PRK-Fuzzer generates reproducible valid and invalid finite 3SAT-to-CLIQUE receipts for stress-testing deterministic reduction checkers.

Rejected overclaims:

- The project does not resolve P vs NP.
- The project does not certify global solver correctness.
- The project does not prove asymptotic optimality.
- The project does not automate all of complexity theory.
- The project does not certify arbitrary reductions outside the declared finite receipt schema.

Use the phrase:

```text
No claim without a receipt.
```
